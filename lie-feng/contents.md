# 裂缝系列 · 总目录

裂缝系列由三层结构、十二部独立著作组成：
- **理论哲学四部**
- **应用观察四部**
- **文学叙事四部**

每一层都是一个独立的阅读入口，每一部都是一部完整独立的著作。三层不是从高到低的等级，而是一个完整的循环——理论提供语言，应用接入现实，文学叙事触及理论和应用都难以抵达的情感深处。

系列核心追问：**你的生命，到底由谁规定？**

### 推荐阅读路径
**路径一：从理论入门开始**（推荐给希望系统理解裂缝系列概念地基的读者）卷一《谁说了算》→ 卷二《裂缝之下》→ 卷三/卷四 → 应用四部（任选）→ 文学四部（任选）

**路径二：从时间/空间维度专深开始**（推荐给对特定维度有强烈兴趣的读者）卷三或卷四 → 卷一/卷二（回溯概念地基）→ 应用四部（任选）→ 文学四部（任选）

 **路径三：从当代问题切入**（推荐给关注当下社会议题的读者）
  卷五/卷六/卷七/卷八（任选）→ 理论四部 → 文学四部

**路径四：从文学叙事进入**（推荐给希望通过故事感受裂缝的读者）
  卷九 → 卷十 → 卷十一 → 卷十二 → 理论四部

 **路径五：从任何一卷开始**每一卷都是独立完整的著作。你可以从任意一卷开始，在任何一卷结束。每卷末尾附有阅读地图，指引可能的下一站。
